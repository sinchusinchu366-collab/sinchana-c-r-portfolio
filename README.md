# Sinchana C R — Portfolio

A modern, responsive single-page developer portfolio showcasing full-stack projects, technical skillset, and academic background.

**Live Site:** https://my-portfolio-q8thudpeo-sinchu6.vercel.app/

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

---

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS 4**
- **Framer Motion**
- **AOS (Animate On Scroll)**
- **EmailJS**
- **WebGL** (Fluid interactive splash cursor)

---

## Run Locally

### 1. Clone & Install
```bash
git clone https://github.com/sinchusinchu366-collab/sinchana-c-r-portfolio.git
cd sinchana-c-r-portfolio
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## Environment Variables

To enable the contact form via EmailJS, create a `.env.local` file in the project root with the following variables:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
